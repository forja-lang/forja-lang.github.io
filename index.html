Lenguaje de programación · v0.10.2

Programá en español.
Compilá a todas partes.

Forja es un lenguaje educativo con contratos y tipado, hecho para aprender de verdad cómo funciona una computadora. Escribís en tu idioma y compilás a nativo, GUI, WASM y Android.

¿Por qué Forja?
 
 
  
100% en español
 
Palabras clave, tipos, errores y documentación en tu idioma. Ideal para quienes aprenden a programar sin pelear con el inglés.
 
 
  
Tipado y contratos
 
Verificador de tipos, borrow checker y design by contract: requiere, asegura e siempre como parte del lenguaje.
 
 
  
Aprendés cómo funciona
 
Un compilador real: lexer, parser, AST, semántica, optimizador, bytecode, VM, JIT y generación de código. Nada de cajas negras.
 
 
  
Un motor, muchas salidas
 
Un mismo programa corre en la VM ForjaFast, en el JIT x86-64, como assembly nativo, como Rust o en el navegador.
 
 
  
Pensado para enseñar
 
Errores con línea, código y sugerencia en español. Un curso de 30 días, 260+ ejemplos y un playground para practicar.
 
 
  
Ecosistema propio
 
Biblioteca estándar, gestor de paquetes, GUI nativa, LSP para tu editor y un depurador integrado.
 
 
 
Un compilador de verdad
 

Forja no es un envoltorio sobre otro lenguaje: tiene su propio pipeline de
    compilación y su propio runtime. Del código fuente salen varios destinos:

 
 
  
VM ForjaFast
 
Intérprete de bytecode con NaN-tagging, stack caching y GC generacional. El destino por defecto al ejecutar.
 
 
  
JIT tiered
 
Compilación en caliente a código máquina x86-64, con niveles y OSR, sobre el mismo bytecode.
 
 
  
Assembly nativo
 
Compilación a código ensamblador x86-64 / ARM64 y enlace con gcc -O2.
 
 
  
Transpilador a Rust
 
Tu programa se convierte en un proyecto Cargo listo para rustc.
 
 
  
WASM / Web
 
El compilador y la VM se empaquetan a WebAssembly: el playground que ves arriba.
 
 
  
Android
 
Runtime nativo vía JNI para llevar tus apps a dispositivos Android.
 
 
 
Forja en acción
 
Una función con contrato y tipo: se verifica antes de ejecutar y falla con un mensaje claro.
 
 
 contratos.fa
 
// El contrato es parte de la firma
funcion dividir(a: Entero, b: Entero) -> Entero
    requiere b != 0, "No se puede dividir por cero"
{
    retornar a / b
}

escribir(dividir(10, 2))   // → 5
dividir(10, 0)            // → error: se incumplió "requiere b != 0"
 
 
Empezá en 5 minutos
 
     
  1. Instalá el compilador — cloná el repo y compilá con cargo build --release (solo necesitás Rust).
    2.  
  2. Escribí tu primer programa — guardá hola.fa con escribir("¡Hola!").
    3.  
  3. Ejecutalo — forja run hola.fa en la VM, o forja build-asm hola.fa para un binario nativo.
    4.  
  4. Seguí con el curso — 30 lecciones progresivas, de variables a GUI, red y SQLite.
    5.  
 
 
 Línea de comandos
 
# Instalar desde el código fuente
git clone https://github.com/forja-lang/forja
cd forja && cargo build --release

# Ejecutar en la VM
forja run ejemplos/fundamentos/01_hola.fa

# Compilar a un binario nativo
forja build-asm ejemplos/fundamentos/01_hola.fa -o programa

# Modo interactivo
forja repl

  Detalle técnico: stack y arquitectura completa 

Forja está escrito en Rust puro. Estos son los componentes principales del
      compilador y el runtime:

 
  
ComponenteMódulo(s)
   
Lexer + Parsercompiler/forja-syntax (tokens, lexer, parser, AST)
 
Semánticacompiler/forja-types (tipos, préstamos, inferencia)
 
HIRcompiler/forja-hir (DefId, módulos, desugar)
 
IR + optimizadorcompiler/forja-ir (SSA, const/copy prop, CSE, DCE, inlining)
 
Bytecodecompiler/forja-bytecode (opcodes, uops, contratos)
 
VM ForjaFastcompiler/forja-vm/src/vm_fast/
 
JIT tieredcompiler/forja-vm/src/jit_tiered.rs
 
GC y heapcompiler/forja-runtime (GC, shapes, Host)
 
Primitivas del sistemacompiler/forja-native (crypto, red, sqlite, ffi)
 
Driver y AOTcompiler/forja-driver (caché incremental, AOT)
 
Compilador ASMsrc/compiler_asm.rs (x86-64 / ARM64)
 
Transpilador Rustsrc/transpiler.rs
 
Backend LLVMsrc/backend_llvm.rs
 
Biblioteca estándarlibrary/std/ (47 módulos)
 
GUI nativalibrary/gui-core/, library/gui-theme/, library/gui-rt/
 
WASMlibrary/wasm/, library/wasm-gui/
 
Herramientassrc/tools/forja-cli, src/tools/forja-lsp, src/tools/forja-dap, src/tools/forja-repl
  
 

Los benchmarks reproducibles viven en benches/ y el pipeline
      canónico se documenta en
