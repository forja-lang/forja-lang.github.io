GUI nativa con Xilem

Forja abre una ventana gráfica nativa con importar gui. Internamente transpila tu código a Rust y usa Xilem con GPU (Vello/wgpu) para renderizar widgets reactivos.

Para ejecutar código GUI necesitás compilar Forja con --features gui y poner destino: nativo en forja.yaml. Si no lo hiciste, visitá Instalación. Los ejemplos de esta página no se ejecutan en el playground del navegador (la GUI necesita el runtime nativo).

Ejemplo mínimo

gui.fa
importar gui

funcion al_saludar() {
    escribir("¡Hola!")
}

funcion main() {
    variable nombre = ""

    tema_fluent(
        columna(
            titulo("Forja GUI"),
            campo_texto("nombre", "Tu nombre"),
            boton_relleno("Saludar", &al_saludar)
        )
    )
}

Ventana

ventana(...) se declara dentro de main y no dibuja nada: configura la ventana nativa (título, tamaño, icono y comportamiento). Los argumentos después de alto son opcionales.

ventana.fa
funcion main() {
    // titulo, ancho, alto, icono, ancho_minimo, alto_minimo, redimensionable, decoraciones
    ventana("Mi app", 1200, 860, "assets/icono.png", 900, 600, verdadero, verdadero)

    tema_fluent(desplazable(columna(...)))
}
ArgumentoDescripción
tituloTexto de la barra. Si falta, se usa el nombre del diseño y el modo.
ancho, altoTamaño inicial en px lógicos (por defecto 1200×800).
iconoRuta a PNG/JPG/BMP/ICO para la ventana y la barra de tareas.
ancho_minimo, alto_minimoTamaño mínimo al redimensionar.
redimensionablefalso = tamaño fijo.
decoracionesfalso = sin barra de título ni borde del sistema (para chrome propio).
Rendimiento: para medir lo que cuesta cada frame, lanzá con FORJA_GUI_PERF=1 y mirá la salida: [perf] 30 frames: 0.31 ms/frame (extraer 0.06 + construir 0.25) | 328/s | 58 widgets por frame. Si compilás a mano con cargo run, agregá el perfil optimizado ([profile.dev.package."*"] opt-level = 3): el stack gráfico sin optimizar es 10-20x más lento y la interacción se siente pegajosa.
Consola: en Windows las apps GUI no abren ventana de consola. Si necesitás ver los errores, pon consola: verdadero en forja.yaml y compilá con forja compilar app.fa. Los logs del runtime están apagados por defecto: activalos con FORJA_GUI_DEBUG=1.

Diseños predeterminados

Forja trae dos diseños listos para usar, cada uno en claro y oscuro. Se aplican envolviendo el layout raíz y afectan colores, radios de borde, superficies y el fondo de la ventana de todo el árbol.

FunciónModoEstilo
tema_fluent(hijo)ClaroFluent (Windows 11): fondo Mica #F3F3F3, acento #005FB8, esquinas 4px y hairline de 1px en tarjetas y campos. Pide el material Mica del sistema cuando el SO está en modo claro
tema_fluent_oscuro(hijo)OscuroFluent oscuro: fondo #202020, acento #4CC2FF; tarjetas al 5% de blanco sobre el fondo
tema_liquid_glass(hijo)ClaroLiquid Glass: fondo vidrioso #F2F6FC, acento #007AFF, esquinas 20-32px y superficies translúcidas
tema_liquid_glass_oscuro(hijo)OscuroLiquid Glass oscuro: fondo #0A0C10, acento #0A84FF

Alias: tema_windows11, tema_vidrio y sus variantes _oscuro. También podés generar un tema Material You desde un color semilla con tema_material("#FF5722", hijo).

Qué define cada diseño: colores del esquema, radios de borde (botones 4/24/20px, tarjetas 4/20/12px según Fluent / Liquid Glass / Material), superficies (fondo de ventana, tarjetas y campos), la paleta de los gráficos y los colores de los widgets nativos (campos, switches, sliders, barras de progreso, botones). La tipografía todavía es la misma en los tres: Xilem no expone una fuente por ventana y habría que fijarla en cada widget.

Cambiar de diseño es cambiar una línea. Las variables de color (color_primario, color_superficie, …) y la tipografía se recalculan solas a partir del tema activo:

cambiar de diseño
// Fluent claro
tema_fluent(columna(...))

// Liquid Glass oscuro
tema_liquid_glass_oscuro(columna(...))

Grid responsivo

grilla(hijos, columnas, gap) usa el grid real de Masonry: las columnas se reparten el ancho disponible (se adaptan al redimensionar la ventana) y cada fila toma la altura de su contenido (autosize). En pantallas angostas baja automáticamente a 2 o 1 columna.

grilla.fa
// 3 columnas que se estiran con la ventana, 16px de separación
grilla([
    tarjeta(columna(titulo("Ventas"), cuerpo_mediano("$1.200"))),
    tarjeta(columna(titulo("Gastos"), cuerpo_mediano("$800"))),
    tarjeta(columna(titulo("Balance"), cuerpo_mediano("$400")))
], 3, 16)

Comandos
