Día 24 · Interfaces gráficas

Forja incluye un sistema de GUI nativa con Material You. Puedes construir ventanas y widgets directamente desde el lenguaje.

Una app mínima

Se importa el módulo gui y se describe la interfaz con funciones de layout como columna, texto_grande y boton.

app.fa
importar "gui"

funcion saludar() {
    escribir("¡Hola!")
}

funcion main() {
    tema_material("#6750A4", columna([
        texto_grande("Mi primera app"),
        espacio(16),
        texto_mediano("Hola, Forja GUI"),
        boton("Saludar", &saludar)
    ]))
}

Ejecutar la app

terminal
forja ejecutar app.fa
Tip: tema_material(seed, contenido) genera una paleta Material You completa a partir de un color semilla y envuelve el layout raíz. Si preferís un diseño listo, usá tema_fluent(contenido) (Windows 11) o tema_liquid_glass(contenido); agregá el sufijo _oscuro para el modo oscuro.
Ejercicio del día: crea una app con un título, un texto y un botón que imprima "clic" en consola al pulsarlo.
